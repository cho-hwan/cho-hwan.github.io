**Master PC D드라이브(하드디스크)에 반드시 이미지가 존재해야합니다. 이를 위해 실습실 맨 앞줄 PC 윈도우 포맷 + 이미지 전송이 Master PC에 한해서 한차례 이루어져야합니다.**

**---용어---**
master PC: 이미지 배포를 해주는 PC
slave PC}: 이미지 배포를 받는 PC

## Master PC 세팅

## 0. 윈도우 포맷 + 이미지 D드라이브에 저장

- **작업을 위해 반드시 "윈도우 부팅 USB, 이미지가 저장된 디스크"가 필요합니다. 60주년 14층에서 받아가세요.**
- **실습실 맨 앞줄 PC를 윈도우 부팅 USB를 통해 윈도우를 재설치해줍니다.**

	1. Windows 설치
	2) Windows 설치 USB를 꽂고 컴퓨터 전원을 킨 다음, 바이오스 진입 키를 연달아 누른다.
		- Dell : Del or F2, HP : ESC or F10, 삼성(TG) : F2, LENOVO : F2
	3) Security 탭에서 “security boot enable” 체크 해제
	4) System → SATA operation → “AHCI”로 체크 후 적용
		- Dell PC는 필수
	5) Boot sequence에 들어가서 USB가 가장 위로 가도록 설정한 후 저장
		- 방향키로 설정 후 Apply
		- 예시(Dell) : “General” → “boot sequence” → UEFI를 위로 올려줌 → “apply” → “EXIT”
	6) 윈도우 설치 중에는 계속 다음을 누르다가 “사용자 지정” 선택한다.
		- 컴퓨터에 따라 윈도우 버전을 선택하는 창이 뜨는데 EDU버전으로 설치
	7) USB 파티션을 제외하고, 모든 파티션 “삭제”하여 할당되지 않은 공간으로 만든다.
		- 절대 USB에 해당하는 파티션은 삭제 X
	8) 파티션0, 파티션1 모두 “새로 만들기” 클릭 후 적용.
	9) (보통 파티션1) SSD(일반적으로 용량이 작은 것) 파티션 내 드라이브가 여러 개 생기는데 새로만들어진 것들 중에 용량이 가장 큰 것을 선택하여 설치
		- 기가바이트, 메가바이트 단위 잘 볼 것.
	10) 설치 중 네트워크 연결 창이 뜨면 다음으로 넘어가지 않ㄷ을 것이기에,
	“Shift + F10” 눌러 cmd창 실행 → oobe\bypassnro 명령어 후 엔터 → 재부팅
	1ㅊ1) 다시 원래 네트워크 연결 창에서 &quot;인터넷에 연결되어 있지 않음“ 선택
	12) 이름은 INHA로 설정하고 비밀번호 설정은 입력하지 않고 “다음” 누른다.
	13) 나머지도 다 "아니요" 클릭 후 완료

- **D드라이브(하드디스크)에 디스크에 저장된 실습실 이미지(해당 실습실 이미지)를 D드라이브(하드디스트)에 "Ctrl+C -> Ctrl+V"해줍니다.**
### 1. "로컬 그룹 정책 편집기" 설치 (Master PC만 진행)

![예제 파일 다운로드](/assets/post/2026-07-20-Image-Deploy/gpedit-code.txt)

- 메모장 메뉴에서 **[파일]** -> **[다른 이름으로 저장]** 클릭
- 파일 형식을 **'모든 파일'** 로 변경해주세요. (이게 제일 중요해요)
- 파일 이름을 **gpedit_install.bat**라고 입력하고 저장합니다. (.bat 확장자가 핵심이에요)
- 생성된 파일 아이콘에 마우스 오른쪽 버튼을 클릭하고 **관리자 권한으로 실행**을 선택합니다.

작업에는 1~2정도가 소요됩니다. 잠시 기다려주세요

- 검은색 프롬프트 창에 **"계속하려면 아무 키나 누르십시오"** 이후 아무 키나 눌러 탭을 닫습니다.
- **Win키+R**을 눌러 실행 창을 열어줍니다.
- **gpedit.msc**를 입력해 로컬 그룹 정책 편집기를 열어줍니다.

- **"컴퓨터 구성" 클릭 -> "관리 템플릿" 클릭 -> "네트워크" 클릭 -> "Lanman 워크스테이션" 클릭 -> "보안되지 않은 게스트 로그온 사용" 사용으로 설정**

### 3. 공유 받기

- **윈도우 검색창에 "₩₩165.246.~.~(이미지를 가진 Master PC의 IPv4)" 입력**
- **이미지파일 "Ctrl+C"      *드래그 앤 드랍 하지마세요.***

- **완료된 PC가 생길때마다 Slave PC를 추가해주시면 됩니다. **
